# Trabajo Final Integrador (TFI) - Aplicación Java con DAO y MySQL

## Descripción
Este proyecto corresponde al **Trabajo Final Integrador (TFI)** de la materia de Programación. La aplicación está desarrollada en **Java 21** y modela dos clases relacionadas mediante una **asociación unidireccional 1→1**, donde la clase `A` referencia a la clase `B`.
## Requisitos:
Verificar que el puerto sea 3306, verificar USER y PASSWORD en **DatabaseConnection.java**

## Pasos para crear la BDD: Primero hay que correr el archivo ArchivoCreacionBDD.sql, que crea la base de datos y luego las tablas
                               Luego hay que correr IngresarRegistros.sql, donde se cargan diferentes registros en las tablas anteriormente creadas
